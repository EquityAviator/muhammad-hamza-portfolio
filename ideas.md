# Design direction

## Theme: Signal / Noise
A dark technical-editorial portfolio that treats Muhammad Hamza Mushtaq's work as a set of observable systems: signals enter, models and software transform them, and usable products come out. The visual language borrows from lab notebooks, terminal traces, and instrument panels without becoming a generic cyberpunk interface.

## Design movement
Calm, high-contrast editorial layouts interrupted by precise amber signal markers, thin grid lines, and animated data paths. The interface should feel authored, not templated.

## Core principles
- Lead with proof: projects and engineering decisions arrive before the biography.
- Use motion to explain systems, not decorate them.
- Make dense technical content scannable through short labels, metrics, and progressive disclosure.
- Keep the palette warm and human against a near-black canvas.
- Be deliberately accessible: visible focus states, semantic HTML, reduced-motion support, and enough contrast.

## Color philosophy
Graphite and warm paper create the base. Amber is the signature signal color for active states and calls to action. Cyan is reserved for research / model information. Plum is used sparingly for trust and integrity systems. No gradients are required for the brand mark; background atmosphere comes from layered radial fields and grid lines.

## Layout paradigm
A single-page narrative with sticky utility navigation, oversized editorial hero type, a responsive system diagram, project cards, and a work modal for deeper case-study summaries. Sections use offset columns and compact index labels to evoke a technical publication.

## Signature elements
- An animated INPUT → MODEL → SYSTEM → OUTPUT diagram in the hero.
- A top-level status beacon: OPEN TO ROLES / RESEARCH / FREELANCE.
- Project cards with signal-color edge rails and measurable evidence.
- Research ladder for CaptionAI with clickable experiment stages.
- Scroll reveal and line-draw motion that pauses under reduced-motion settings.

## Typography system
Use Space Grotesk for display and body text, IBM Plex Mono for metadata, labels, code-like annotations, and system traces.

## Brand essence and voice
Clear, rigorous, curious, quietly confident. Explain what was built and why, call out trade-offs, and avoid inflated claims.

## Wordmark / logo
A compact HM monogram built from two intersecting signal bars and a dot, rendered as CSS/SVG geometry so it remains crisp at favicon size.
